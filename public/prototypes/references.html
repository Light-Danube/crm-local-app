UI референси для наступних ітерацій

Збережено 20 жовтня 2026. Нижче — власні схеми патернів із документації шести продуктів, а не скриншоти їхніх інтерфейсів. Оригінальні приклади та контекст доступні за посиланнями.

Інтерактивний прототип робочого простору буде додано окремою невеликою зміною.

ScreenCloud

Official help guide
enter the 6-character pairing code exactly how it appears
Код на екрані → Додати екран → Список екранів

Явна дія додавання екрана, поле коду, повідомлення про помилку й список підключених екранів.

Для нас: Показати контекст коду й статуси. У нас код створює пульт, а вводить екран — напрямок не змінюємо.

Документація описує комерційний signage-продукт; не переносимо акаунти, ліцензії та CMS.

Документація ScreenCloud

Yodeck

Official registration guide
Type the Registration Code in the Registration Code field.
Пристрій готовий → Поле коду → Підтвердження

Пряме введення коду для досвідченого користувача та контекстна допомога для першого запуску.

Для нас: Одне підписане поле на шість цифр; допомога біля поля. Вставлення й Enter працюють без шести окремих boxes.

Yodeck використовує інший формат і напрямок реєстрації. Наші шестизначний код, TTL та auth лишаються чинними.

Документація Yodeck

OptiSigns

Official setup guide
Set up & add a screen
Приєднати → Вибрати контент → Передати на екран

Окремі кроки приєднання екрана, завантаження контенту й призначення контенту.

Для нас: Розділити «обрати джерело» та «передати», показати порожній стан без медіа.

Не додаємо бібліотеку, schedules чи завантаження в хмару — це інший обсяг продукту.

Документація OptiSigns

ProPresenter

Official interface guide
Below the Preview window is the screen drop-down indicator along with the transport controls.
Джерело → Preview + playback → Додаткові параметри

Preview та транспортні кнопки поруч; складніші функції згруповано окремо.

Для нас: Play/pause/seek/volume перед effects; повний набір ефектів доступний через details.

Це структурний референс ProPresenter, не твердження про останню версію чи поточний pixel layout.

Документація ProPresenter

Watch2Gether

Official community guide
On Desktop, click “Invite” in the sidebar on the left side of the room.
Створити кімнату → Запросити → Обрати відео

Окрема дія запрошення та розрізнення вибору джерела й взаємодії з playback.

Для нас: Дія приєднання має бути постійно видимою. URL джерела вводиться прямо, без прихованого меню.

Гостьове shared control не переносимо; owner лишається єдиним controller. Не копіюємо invitation tokens у URL.

Документація Watch2Gether

Syncplay

Official client guide
Syncing playback with a large group of strangers? Consider using managed rooms
З’єднання → Медіа → Відтворення

Окремі connection/media settings, додаткові параметри за Show more settings та керовані кімнати.

Для нас: Мінімум полів для приєднання; розширені налаштування закриті за замовчуванням.

Syncplay потребує зовнішніх media players. Не переносимо його мережеві чи stream-гарантії в браузерний застосунок.

Документація Syncplay
